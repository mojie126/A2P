# agent2api-providers 3.5.0 资产草稿（fork）

基于官方 3.5.0（`4f4ad5e`）；官方发布说明见 <https://github.com/ProvidersPlugin/Agent2Providers/releases/tag/v3.5.0>，官方改动（提供商拆分 WASM 插件等）不在本文件重复列出。本文件只列 fork 相对官方版本的增量改动：本仓库维护原生插件包，`crates/` 下的实现独立演进，WASM 架构不迁。同版本的多次构建在本文件整合或追加。本版本相对 3.5.0-beta.2 只有版本号对齐，无实体改动。

## 新增

- 新增：CodeArts 签到链纳入每日签到礼与一次性报名礼，新手福利页同步展示 Skill 创新赛报名礼
- 新增：百度搭子（DuMate）提供商接入：网页 Cookie 粘贴与受控浏览器登录，OpenAI 兼容对话转发，静态模型目录，余额查询与每日签到
- 新增：DeepAI Code 提供商接入：对话、动态模型目录、额度与签到、订阅摘要、粘贴 API Key 与本机凭据读取
- 新增：科搭（Codar）提供商接入：JWT 令牌导入、动态模型目录、点数余额、每日签到、提前续期

## 修复

- 修复：插件 Linux x86_64 构建使用 `target-cpu=x86-64` 通用指令集，避免旧处理器 SIGILL 无法启动
- 修复：小浣熊对话请求头对齐官方桌面客户端 1.1.9（Issue #542）
- 修复：百度搭子流式对话补 `stream_options.include_usage` 注入，此前 token 与缓存命中全记 0
- 修复：ZCode 活动目录为空时仍回读账号名下已领取套餐
- 修复：百度搭子用完的积分包在所有位置排除，不再显示空窗口行

## 优化

- 优化：ZCode 客户端版本默认值对齐真实客户端 3.17.2
- 优化：果办新增只读客户端状态模拟，只返回白名单字段
- 优化：Trae 收尾帧发送前查逐轮账单补缓存命中计数，整体预算封顶 12 秒
- 优化：Trae 逐包读数缺失时回退上游汇总剩余积分，不再把 SOLO 并发数当余额
- 优化：CodeArts 对话转发前移除 `stop` 字段，并补全华为网关复合业务码到状态码的映射
- 优化：清理三处 `expect`，满足 crates 级零 panic 约定

## 其它

- 更新：README 支持矩阵同步登记 CodeArts 签到与百度搭子，英文与简体中文口径一致
- 更新：dev-build 官方 action 升级 v7，消除 Node.js 20 弃用告警
- 更新：dev-build 增加 pack.json 与 Cargo 版本一致性校验，发布说明按版本号推导
- 版本：3.5.0-beta.1 → 3.5.0-beta.2
